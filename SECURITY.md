# Política de segurança

Encontrou uma vulnerabilidade? **Não abra uma issue pública.**
Envie os detalhes para o e-mail do mantenedor (ou use "Report a vulnerability" na aba *Security* do GitHub).
Respondemos em até 72 horas e avisamos quando a correção for publicada.

Detalhes técnicos das proteções: [docs/SEGURANCA.md](docs/SEGURANCA.md).
